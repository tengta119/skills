## 研究问题与背景
Deutsch-Jozsa、Bernstein-Vazirani、Simon 等早期量子算法各自提出了量子计算中的突破性概念，但它们所求解的问题几乎都没有实用价值，因而通常被认为仅属理论范畴；不过它们相对经典算法呈指数级加速。作者要做的有两件事：一方面综述对这些早期算法“再思考”的最新进展，另一方面对它们进行“重新目的化”，即重新用于量子密钥分发（QKD）、纠错等领域（p.2 摘要、引言）。Shor 与 Grover 算法已有明确用途，而这三类算法长期被视为纯理论，是本文重新审视的对象（p.2）。

## 方法、假设、核心公式与算法
本文是解释性综述，逐一回顾三种算法及其改造应用：

- Deutsch-Jozsa（D-J）（p.2–3）：判定布尔函数 f:{0,1}^n→{0,1} 是常数还是平衡。oracle 为 U_f:|x>|y>→|x>|y⊕f(x)>；从 |0>^n|1> 出发，经 n+1 位 Hadamard、oracle 与相位反冲、再 Hadamard，测第一个寄存器：f 为常数时以概率 1 观察到 |0>^n（相长干涉），f 为平衡时概率为 0（相消干涉）。Nagata 等把它用于基于 GHZ 态与 Ekert'91 协议的 QKD：Alice 制备 |ψ1> 发给 Bob，Bob 选函数、施加 oracle 与 Hadamard 后回传前 n 个量子位，Alice 做 GHZ 测量以判断函数类型，函数类型即共享密钥；若函数为常数而测量结果不为 1，说明 Eve 窃听。
- Bernstein-Vazirani（B-V）（p.3–4）：f(x)=ξ·x，任务是由查询找出 ξ。初态 |0>^n|1>，经 H、oracle、再 H 后得到 ±|ξ>，一次查询即可；经典算法需 2^{n/2}+1 次查询。用于 QKD 时 Alice 只需问一个问题即可获知 Bob 选定的 n 位字符串，比经典情形快 n 倍；用于纠错时令 f(x)=g(x)⊕h(x)，g(x)=γ·x、h(x)=η·x（γ 为 Bob 的字符串、η 为 Alice 的字符串），Alice 测量第一个寄存器得到 γ⊕η，据此定位与 Bob 通信中的比特错误。
- Simon（p.4）：f(x)=f(x⊕ξ)，任务是找周期 ξ。算法用 O(n) 次 oracle 查询，经典算法至少需 Ω(2^{n/2}) 次；用于 QKD 时 Alice 制备 2n 量子位态、Bob 施加 oracle，Alice 经 Hadamard 与测量获知 ξ，双方共享 n 位密钥。
- 隐子群问题（p.4–5）：上述算法都可归约为隐子群问题。D-J 的群 G=Z_2^n（常数时隐藏子群 H=Z_2^n，平衡时 H={0}）；B-V 的 H={z∈Z_2^n: ξ·z=0}；Simon 的 H={0,ξ}；Shor 算法对应的群为阿贝尔群，故可多项式时间实现。

文中未提出新算法、未给出新证明，也未做实验；比较均引用原文献的 oracle 查询复杂度。

## 核心结论与结果
- D-J 可改造为基于 Ekert'91 协议的安全 QKD，且相对经典算法有指数级优势；其修改版还被用于形式语言中区分平凡与非平凡单词（p.3）。
- B-V 的 QKD 协议比经典协议快 n 倍；其纠错应用可通过测量 γ⊕η 检测 Alice 与 Bob 通信中的错误（p.4）。
- Simon 的 QKD 协议同样可共享 n 位密钥（p.4）。
- 作者指出 B-V 与 Simon 的 QKD 协议均未使用纠缠，安全性不及基于 D-J 的协议；B-V 协议还可能包含传输错误（p.4）。
- 三种算法均可归约为隐子群问题，这解释了它们在密码学中的共同适用性（p.5）。

## 局限与适用边界
作者明确指出：D-J 密钥分发协议在 Bob 选择平衡函数时无法检测 Eve 的监听，因为平衡函数对应的 |ψ2> 本身就是纠缠态，窃听对纠缠的破坏不易分辨（p.3）；B-V 与 Simon 的密钥分发协议未使用纠缠，安全性不及 D-J 方案，B-V 协议还可能包含传输错误（p.4）。

阅读者推断：全文为定性综述，未评估各协议在实际噪声信道、有限密钥长度与器件不完美条件下的性能；“指数级加速”均以 oracle 查询次数计，未计入量子门数、电路深度或纠错开销（依据 p.2–4 的复杂度表述仅涉及查询次数）。

## 相关工作与潜在研究方向
文内脉络：Deutsch-Jozsa 1992、Bernstein-Vazirani 1992、Simon 1994、Grover 1996、Shor 1997（p.2）；Nagata 等 2017 的 D-J QKD、Nguyen 与 Kim 2019 的 d 级推广、Batty 等 2008 的形式语言应用（p.3）；Nagata 等 2017 的 B-V QKD 与纠错、Xie 与 Yang 2019 用 B-V 攻击分组密码（p.4）；Nagata 等 2017 的 Simon QKD、Cui 等 2021 用 Simon 攻击 Feistel 变体（p.4）。未来方向：在隐子群问题框架内尝试各种阿贝尔群以寻找新的多项式时间算法；为已有快速量子算法寻找新应用；作者还提到 Grover、量子模拟与整数分解可归约为奇异值转换问题（p.5）。

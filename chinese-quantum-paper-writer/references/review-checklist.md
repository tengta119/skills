# 终稿审查清单

逐项填写 PASS / FAIL / N/A 与证据、责任人、修订建议；不得把未检查的项目视为通过。

- [ ] 选题、论文类型、目标期刊与用户批准版本一致。
- [ ] 文献覆盖、筛选方法、未获得全文、时间边界均如实说明。
- [ ] 研究空白有证据，未将局部未检索到写成全球首次。
- [ ] 摘要、引言贡献、方法、结果和结论相互一致。
- [ ] 每个重要事实与原文证据语义相符；不存在引用不存在的文献、伪造 DOI 或漏引。
- [ ] 他人成果与本文贡献清晰区分，转引明确，图表许可已审查。
- [ ] 原创论文有真实方法、证明/实验；实验日志、环境、数据、随机性与图表可追溯。
- [ ] 比较公平，基线合理；失败结果、误差与限制未被隐藏。
- [ ] 区分量子/量子启发式、经典仿真/噪声仿真/硬件结果、量子密码/后量子密码。
- [ ] 术语、符号、公式、单位、缩写与章节编号一致。
- [ ] 图表存在且正文引用正确；中文及英文摘要一致。
- [ ] 引文与参考文献一一对应，著录按目标期刊最新要求核验。
- [ ] 不存在待核验、待实验、模板占位符或无依据的性能数字（未完成稿例外，明确标注）。
- [ ] 写作版机械引用检查通过，语义核验矩阵完整。
- [ ] AI 使用披露、数据许可、保密、作者贡献与其他伦理要求由用户核实。

严重问题（虚构/未核验引文、无原始实验、错误证明、结论失实）必须阻止标记为终稿；若无法修复，交付标注为“未完成草稿”，附阻塞事项。审查本身不是同行评审或录用保证。
